Chrome의 브라우징 데이터를 빠르게 정리하는 간단하고 안전한 클린업 확장 프로그램입니다.
도구 모음 아이콘을 클릭하고, 삭제할 항목과 기간을 선택한 뒤 버튼을 두 번 누르면 끝납니다.

■ 주요 기능

・원클릭 일괄 삭제
  팝업에서 현재 설정 그대로 한 번에 정리합니다. 복잡한 설정 화면을 오갈 필요가 없습니다.

・10가지 데이터 중에서 선택
  방문 기록, 캐시, 쿠키, 다운로드, 양식 데이터는 물론 사이트가 브라우저 안에 저장한 데이터도 삭제할 수 있습니다. 필요한 항목만 자유롭게 조합할 수 있습니다.

・기간 지정
  삭제 대상 기간을 "최근 1시간", "최근 24시간", "최근 1주", "최근 4주", "전체"의 5단계에서 선택할 수 있습니다.

・두 번 눌러 확인하여 오조작 방지
  "삭제" 버튼은 처음 누르면 "한 번 더 눌러 확인" 상태로 바뀌고, 5초 안에 두 번째로 누르면 실행됩니다. 잘못 눌러 세션이 사라질 위험을 크게 줄입니다.

・Chrome 시작 시 자동 삭제
  "Chrome 시작 시 자동으로 삭제"를 사용하면 브라우저를 시작할 때마다 자동으로 정리를 실행합니다. 사용하는 동안에는 로그아웃 등의 영향을 알리는 안내 문구가 팝업에 표시됩니다.

・시작 시 탭 자동 새로고침
  시작 시 자동 삭제로 캐시, 쿠키, 사이트가 브라우저 안에 저장한 데이터를 삭제한 경우, 열려 있던 일반 웹 탭을 나누어 순차적으로 새로고침하여 삭제 후의 최신 상태로 자동 갱신합니다.

・삭제 후 탭 자동 새로고침(선택)
  "삭제 후 모든 HTTP 탭을 자동으로 새로고침"을 사용하면 삭제가 끝난 뒤 열려 있는 HTTP/HTTPS 탭을 한꺼번에 자동으로 새로고침합니다. 삭제한 데이터를 표시한 채 남아 있는 탭이 없습니다.

・정리는 로컬에서 완결
  삭제 처리와 설정 저장은 브라우저 안에서 완결됩니다. 사용자가 선택적 문의 양식을 제출할 때만 입력한 내용을 Kagayoi Support로 보냅니다. 추적, 분석, 원격 측정은 없습니다.

■ 사용 방법

1. Chrome 웹 스토어에서 설치
2. 도구 모음의 Clean Start 아이콘 클릭
3. "삭제할 데이터"의 체크박스에서 삭제할 데이터 유형 선택
4. "기간"에서 시간 범위 선택
5. "삭제" 버튼 누르기 → "한 번 더 눌러 확인"이 표시되면 5초 안에 한 번 더 누르기
6. 완료!

모든 설정은 팝업 안에서 완결됩니다. 설정값은 브라우저에 저장되어 다음에 팝업을 열 때도 그대로 유지됩니다.
