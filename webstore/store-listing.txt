[Store Listing]
------------------------------------------------------------

■ Name (max 30 chars)
Clean Start

■ Summary (max 132 chars)
One-click cleanup for history, cache, cookies, and site data. 10 data types, 5 time ranges, two-tap confirm to prevent accidents.

■ Description (max 16,000 chars)
A simple, safe cleanup extension for tidying up Chrome's browsing data.
Click the toolbar icon, choose what to delete and over which time range,
then tap the button twice — that's it.

■ Key features

- One-click bulk cleanup
  Run a full cleanup with the current settings directly from the popup.
  No need to navigate through nested settings screens.

- Pick from 10 data types
  History, cache, cookies, downloads, and form data, plus the data that
  sites keep inside the browser. Combine only the ones you need.

- Time-range selection
  Choose from "Last hour", "Last 24 hours", "Last week", "Last 4 weeks",
  or "Everything" for the deletion window.

- Two-tap confirm to prevent accidents
  The Clear button switches to a "Tap again to confirm" state on the
  first tap. The second tap within 5 seconds runs the actual cleanup.
  Greatly reduces the risk of accidentally wiping sessions.

- Optional auto-clear on Chrome startup
  Enable "Clear automatically when Chrome starts" to wipe data on every
  launch. A warning banner appears in the popup so you don't enable it
  accidentally.

- Auto-reload startup tabs
  When auto-clear runs cache- or cookie-related deletions on startup,
  open web tabs are reloaded in batches so you immediately see fresh
  pages.

- Optional tab reload after Clear
  Enable "Automatically reload all HTTP tabs after clearing" and every
  open HTTP/HTTPS tab refreshes automatically once cleanup completes,
  so no tab is left showing data that was just deleted.

- Local cleanup, no tracking
  Cleanup and settings stay inside the browser. Only when you submit the
  optional contact form are your entered details sent to Kagayoi Support.
  There is no tracking, analytics, or telemetry.

■ How to use

1. Install from the Chrome Web Store.
2. Click the Clean Start icon in the toolbar.
3. Tick the data types you want to delete under "Deletes".
4. Pick a time range under "Time Period".
5. Tap the Clear button. When it changes to "Tap again to confirm",
   tap it again within 5 seconds.
6. Done!

All settings live inside the popup. Your selections are stored locally
and remain in place the next time you open the popup.

[Privacy Practices]
------------------------------------------------------------

■ Single purpose
Yes

■ Single purpose description
Bulk-deletes Chrome's history, cache, cookies, and site storage
based on the user's selected data types and time range, and provides a
user-initiated support contact form for this extension.

■ Data usage disclosures

  - Personally identifiable information collected? Yes, only when the
    user submits the optional contact form: email address and optional name
  - User data handled? Yes, only user-entered contact details, inquiry
    content, the email verification code, and the support-session access
    token used to authenticate the support request

  - User data handling commitments
    - Will not sell user data
    - Will not use or transfer user data for purposes unrelated to the
      item's single purpose
    - Will not use or transfer user data to determine creditworthiness
      or for lending purposes

■ Permission justifications

  storage:
  Used to persist the user's choices locally via chrome.storage.local:
  selected data types (dataToRemove), time range (timePeriod), the
  "auto-reload after clear" flag (autorefresh), and the "clear on Chrome
  startup" flag (clearonstartup). Nothing is transmitted externally.

  browsingData:
  Core feature. Calls chrome.browsingData.remove() to delete the data
  types the user selected (history, cache, cookies, IndexedDB, service
  workers, etc.) for the chosen time range.

  tabs:
  Used only when the user has enabled "Automatically reload all HTTP
  tabs after clearing", and on startup auto-clear. Open tabs are
  enumerated to filter HTTP/HTTPS targets and reload them so the user
  sees a fresh state. chrome.browsingData clears data for the whole
  profile, so reloading only the active tab would leave other tabs
  showing stale content. Tab URLs and titles are never logged, stored,
  or transmitted anywhere.

  host_permissions (https://support.kagayoi.com/*):
  Used only when the user opens and submits the optional contact form.
  It sends the email verification request and the support ticket entered
  by the user to Kagayoi Support over HTTPS. Cleanup settings, browsing
  history, and tab URLs are never sent.

■ External server communication
Cleanup does not communicate with an external server. Only when the user
submits the optional contact form does the extension send the entered
email address, optional name, inquiry content, product/version/locale
metadata, email verification code, and support-session access token to
https://support.kagayoi.com.

■ Remote code
No.
All code is bundled inside the extension package; no remote scripts are
loaded. Content Security Policy is set explicitly to
`script-src 'self'; object-src 'self'`.

【ストアの掲載情報】タブ
------------------------------------------------------------

■ 名前（30文字以内）
Clean Start

■ 概要（132文字以内）
履歴・キャッシュ・Cookie・サイト保存データを 10 種から選んでワンクリックで一掃。期間指定と 2 段階確認で安心して使える、軽量・無料の Chrome 拡張機能。

■ 説明（16,000文字以内）
Chrome の閲覧データをすばやく整理するための、シンプルで安全なクリーンアップ拡張機能です。
ツールバーのアイコンをクリックして、削除したい項目と期間を選び、ボタンを 2 回タップするだけで完了します。

■ 主な機能

・ワンクリックの一括削除
  ポップアップから現在の設定でまとめてクリーンアップ。複雑な設定画面を行き来する必要はありません。

・10 種類のデータから選択
  履歴、キャッシュ、Cookie、ダウンロード履歴、フォームデータに加え、サイトがブラウザ内に保存したデータも対象。必要な項目だけを自由に組み合わせて削除できます。

・期間指定
  「1時間以内」「24時間以内」「1週間以内」「4週間以内」「すべて」の 5 段階から削除対象期間を選べます。

・2段階タップで誤操作防止
  Clear ボタンは初回タップで「もう一度タップで削除」状態に切り替わり、5 秒以内に 2 回目をタップすると実行されます。誤クリックでセッションが消えるリスクを大幅に低減。

・Chrome 起動時の自動削除
  「Chrome 起動時に削除する」を有効にすると、ブラウザを起動するたびに自動でクリーンアップを実行。設定画面には destructive 性を伝える警告バナーを併記。

・起動時タブの自動リロード
  起動時自動削除でキャッシュ系・Cookie 系を消した場合、開いていた通常の Web タブをバッチで段階的にリロードして、消去後の最新状態に自動で更新。

・削除後のタブ自動再読み込み（任意）
  「削除後に全 HTTP タブを自動で再読み込みする」を有効にすると、Clear 押下後に開いている HTTP/HTTPS タブをまとめて自動リロード。削除済みデータを表示したままのタブが残りません。

・クリーンアップはローカル完結
  削除処理と設定保存はブラウザ内で完結します。任意のお問い合わせフォームを利用者が送信したときだけ、入力内容を Kagayoi Support へ送ります。トラッキング・解析・テレメトリはありません。

■ 使い方

1. Chrome Web Store からインストール
2. ツールバーの Clean Start アイコンをクリック
3. 「削除する項目」のチェックボックスで対象データ型を選ぶ
4. 「対象期間」のラジオボタンで時間範囲を選ぶ
5. Clear ボタンをタップ → 「もう一度タップで削除」が出たら 5 秒以内にもう一度タップ
6. 完了！

すべての設定はポップアップ内で完結します。設定値はブラウザ内に保存され、次回ポップアップを開いた際もそのまま保持されます。

【プライバシーへの取り組み】タブ
------------------------------------------------------------

■ このアイテムに単一の目的はありますか？
はい

■ 単一の目的の説明
ユーザーが選択した期間とデータ型に基づいて Chrome の履歴・キャッシュ・Cookie・サイト保存データを一括削除し、この拡張機能について利用者が任意で問い合わせできるようにする。

■ データの使用に関する開示

  ・個人を特定できる情報を収集しますか？
    はい。任意のお問い合わせフォームを利用者が送信した場合に限り、メールアドレスと任意入力のお名前を受け取ります。

  ・ユーザーのデータを取り扱いますか？
    はい。利用者が入力した問い合わせ内容、連絡先、メール確認コード、お問い合わせ認証用のサポートセッショントークンだけを問い合わせ対応のために取り扱います。クリーンアップ設定はブラウザ内だけに保存します。

  ・ユーザーデータをどのように扱いますか？
    - ユーザーデータの販売: しない
    - ユーザーデータの本来の目的以外への使用や転送: しない
    - 信用力の判定や貸付目的での使用や転送: しない

■ 権限の正当性

  storage:
  ユーザーが選択した削除対象（dataToRemove）、期間（timePeriod）、自動再読み込みフラグ（autorefresh）、Chrome 起動時自動削除フラグ（clearonstartup）を chrome.storage.local にローカル保存するために使用します。データは外部に送信されません。

  browsingData:
  本拡張機能の中核機能です。chrome.browsingData.remove() を呼び出して、ユーザーが指定した期間とデータ型（履歴、キャッシュ、Cookie、IndexedDB、Service Workers など）をまとめて削除するために使用します。

  tabs:
  ユーザーが「削除後に全 HTTP タブを自動で再読み込みする」を有効にした場合と、起動時自動削除の後に使用します。開いているタブを列挙して HTTP/HTTPS のものだけを reload し、削除後の最新状態を表示するために使います。chrome.browsingData はプロファイル全体のデータを消すため、アクティブタブだけを reload すると他のタブが古い内容を表示したままになります。タブの URL やタイトルはログ出力・保存・外部送信を一切行いません。

  host_permissions（https://support.kagayoi.com/*）:
  利用者が任意のお問い合わせフォームを開いて送信したときだけ使用します。メール確認と利用者が入力した問い合わせを HTTPS で Kagayoi Support へ送ります。クリーンアップ設定、閲覧履歴、タブ URL は送信しません。

■ 外部サーバーとの通信について
クリーンアップ処理は外部サーバーと通信しません。任意のお問い合わせフォームを利用者が送信したときだけ、メールアドレス、任意入力のお名前、問い合わせ内容、製品・バージョン・ロケール情報、メール確認コード、サポートセッショントークンを https://support.kagayoi.com へ送信します。

■ リモートコードを使用していますか？
いいえ
（すべてのコードは拡張機能パッケージ内に含まれており、外部からのコード読み込みは一切行いません。Content Security Policy で `script-src 'self'; object-src 'self'` を明示しています。）
