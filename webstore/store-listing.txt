【ストアの掲載情報】タブ
------------------------------------------------------------

■ 名前（30文字以内）
Clean Start

■ 概要（132文字以内）
履歴・キャッシュ・Cookie・サイト保存データを 10 種から選んでワンクリックで一掃。期間指定と 2 段階確認で安心して使える、軽量・無料の Chrome 拡張機能。

■ 説明（16,000文字以内）
Chrome の閲覧データをすばやく整理するための、シンプルで安全なクリーンアップ拡張機能です。
ツールバーのアイコンをクリックして、削除したい項目と期間を選び、ボタンを 2 回タップするだけで完了します。

■ 主な機能

・ワンクリックの一括削除
  ポップアップから現在の設定でまとめてクリーンアップ。複雑な設定画面を行き来する必要はありません。

・10 種類のデータから選択
  履歴、キャッシュ、Cookie、ダウンロード履歴、フォームデータに加え、サイトがブラウザ内に保存したデータも対象。必要な項目だけを自由に組み合わせて削除できます。

・期間指定
  「1時間以内」「24時間以内」「1週間以内」「4週間以内」「すべて」の 5 段階から削除対象期間を選べます。

・2段階タップで誤操作防止
  「削除する」ボタンは初回タップで「もう一度タップで削除」状態に切り替わり、5 秒以内に 2 回目をタップすると実行されます。誤クリックでセッションが消えるリスクを大幅に低減。

・Chrome 起動時の自動削除
  「Chrome起動時に削除する」を有効にすると、ブラウザを起動するたびに自動でクリーンアップを実行。有効にしている間は、ログアウトなどの影響を伝える注意書きをポップアップに表示します。

・起動時タブの自動リロード
  起動時自動削除でキャッシュ・Cookie・サイトがブラウザ内に保存したデータを消した場合、開いていた通常の Web タブをバッチで段階的にリロードして、消去後の最新状態に自動で更新。

・削除後のタブ自動再読み込み（任意）
  「削除後に全 HTTP タブを自動で再読み込みする」を有効にすると、削除の完了後に開いている HTTP/HTTPS タブをまとめて自動リロード。削除済みデータを表示したままのタブが残りません。

・クリーンアップはローカル完結
  削除処理と設定保存はブラウザ内で完結します。任意のお問い合わせフォームを利用者が送信したときだけ、入力内容を Kagayoi Support へ送ります。トラッキング・解析・テレメトリはありません。

■ 使い方

1. Chrome Web Store からインストール
2. ツールバーの Clean Start アイコンをクリック
3. 「削除対象データ」のチェックボックスで対象データ型を選ぶ
4. 「対象期間」で時間範囲を選ぶ
5. 「削除する」ボタンをタップ → 「もう一度タップで削除」が出たら 5 秒以内にもう一度タップ
6. 完了！

すべての設定はポップアップ内で完結します。設定値はブラウザ内に保存され、次回ポップアップを開いた際もそのまま保持されます。

【プライバシーへの取り組み】タブ
------------------------------------------------------------

■ このアイテムに単一の目的はありますか？
はい

■ 単一の目的の説明
ユーザーが選択した期間とデータ型に基づいて、Chrome の履歴・キャッシュ・Cookie・サイト保存データを、ボタン操作または Chrome 起動時に一括削除する。

■ データの使用に関する開示

  ・収集するデータの種類（チェックを入れるもの）:
    - 個人を特定できる情報
    - 認証に関する情報
    - 個人的コミュニケーション
    任意のお問い合わせフォームを利用者が送信した場合に限り、メールアドレス、任意入力のお名前、問い合わせ内容、メール確認コード、お問い合わせ認証用のサポートセッショントークンを受け取り、問い合わせ対応のためだけに取り扱います。クリーンアップ設定はブラウザ内だけに保存します。

  ・収集しないデータの種類:
    健康に関する情報、財務状況や支払いに関する情報、位置情報、ウェブ履歴、ユーザーのアクティビティ、ウェブサイトのコンテンツ

  ・ユーザーデータをどのように扱いますか？（3 つともチェック）
    - ユーザーデータの販売: しない（承認されている以外の用途で第三者にユーザーデータを販売、転送しません）
    - ユーザーデータの本来の目的以外への使用や転送: しない（アイテムの唯一の目的と関係のない目的でユーザーデータを使用または転送しません）
    - 信用力の判定や貸付目的での使用や転送: しない（信用力を判断する目的または融資目的でユーザーデータを使用または転送しません）

■ 権限の正当性

  storage:
  ユーザーが選択した削除対象（dataToRemove）、期間（timePeriod）、自動再読み込みフラグ（autorefresh）、Chrome 起動時自動削除フラグ（clearonstartup）を chrome.storage.local にローカル保存するために使用します。データは外部に送信されません。

  browsingData:
  本拡張機能の中核機能です。chrome.browsingData.remove() を呼び出して、ユーザーが指定した期間とデータ型（履歴、キャッシュ、Cookie、IndexedDB、Service Workers など）をまとめて削除するために使用します。

  tabs:
  手動削除で「削除後に再読み込み」が有効な場合と、Chrome 起動時の自動削除でキャッシュ・Cookie・サイト保存データを削除した場合に、開いている http/https タブを列挙して再読み込みするために使用します。タブの URL は対象の絞り込みにだけ参照し、保存・外部送信は行いません。

  host_permissions（https://support.kagayoi.com/*）:
  利用者が任意のお問い合わせフォームを開いて送信したときだけ使用します。メール確認と利用者が入力した問い合わせを HTTPS で Kagayoi Support へ送ります。クリーンアップ設定、閲覧履歴、タブ URL は送信しません。

■ 外部サーバーとの通信について
クリーンアップ処理は外部サーバーと通信しません。任意のお問い合わせフォームを利用者が送信したときだけ、メールアドレス、任意入力のお名前、問い合わせ内容、製品・バージョン・ロケール情報、メール確認コード、サポートセッショントークンを https://support.kagayoi.com へ送信します。

■ リモートコードを使用していますか？
いいえ
（すべてのコードは拡張機能パッケージ内に含まれており、外部からのコード読み込みは一切行いません。Content Security Policy で `script-src 'self'; object-src 'self'` を明示しています。）
