Clean Start の基本仕様

データ種別
履歴 / キャッシュ / Cache Storage / Cookie / ダウンロード / File Systems / フォームデータ / IndexedDB / Local Storage / Service Worker / Web SQL / App Cache
期間
1 時間 / 24 時間 / 1 週間 / 4 週間 / 全期間
確認
1 回目で確認状態へ、5 秒以内の 2 回目で実行
自動クリア
任意で有効化できるオプション機能

Chrome の設定画面を何階層もたどらずに、ポップアップだけで完結します。

01

消す対象を選ぶ

12 種類のデータから、消したいものだけをチェックします。設定は次回も保持されます。

02

期間を決める

直近 1 時間から全期間まで、5 段階の削除範囲を選べます。

03

2 回タップで実行

1 回目で確認状態に切り替わり、5 秒以内の 2 回目で実際の削除が走ります。

FEATURES

毎回同じ掃除なら、
自動でもいい。

よく使う組み合わせを保存しておけば、ポップアップを開いて 2 タップするだけ。任意で自動クリアを有効にすることもできます。

  • 12 種類のデータ種別を自由に組み合わせ
  • 5 段階の期間指定
  • 任意の自動クリア機能

対象と処理の一覧

データ種別状態処理

パスワード対象外KEEP

CONFIRM STATE tap 1 → 「もう一度で確定」 5s window 5 秒を過ぎると自動で通常状態へ戻り、削除は実行されない

DESIGN PRINCIPLES

SAFE

誤操作を前提に設計

セッションを吹き飛ばす事故を、2 回タップ確認で構造的に防ぎます。

LOCAL

設定は端末内だけ

選択状態はローカルに保存され、外部へは送信されません。

FAST

ポップアップで完結

設定画面をたどらず、開いてすぐ掃除できる導線にしています。
