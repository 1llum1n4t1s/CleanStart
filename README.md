# Clean Start

履歴、キャッシュ、Cookie、各種サイト保存データを、ポップアップからまとめて削除できる Chrome 拡張機能です。

## インストール

ソースを利用する場合は、リポジトリをダウンロードして展開し、Chrome の `chrome://extensions` でデベロッパーモードを有効にします。「パッケージ化されていない拡張機能を読み込む」から `manifest.json` があるフォルダーを選んでください。

## 使い方

1. Chrome の拡張機能メニューから Clean Start を開きます。
2. 削除したいデータと期間を選び、上部の要約を確認します。設定は自動保存されます。
3. 削除ボタンを押し、5秒以内にもう一度押すと削除が始まります。確認中に5秒経つと元の状態に戻ります。

削除は現在の Chrome プロファイル全体に適用されます。サイトやドメインを指定して削除する機能はありません。

## 削除対象と設定

- 対象はキャッシュ、Cache Storage、Cookie、ダウンロード履歴、ファイルシステム、フォームデータ、閲覧履歴、IndexedDB、Local Storage、Service Worker です。キャッシュと Cache Storage は別々に選択できます。
- 期間は過去1時間・1日・1週間・4週間・全期間から選べます。4週間は28日として扱います。
- 初期選択はキャッシュ、Cache Storage、ファイルシステム、IndexedDB、期間は過去1時間です。
- 「削除後に自動再読み込み」を有効にすると、手動削除後に全 HTTP(S) タブを順次再読み込みします。
- 「Chrome 起動時に自動削除」を有効にすると、保存した対象と期間で確認操作なしに削除します。キャッシュ・Cookie・サイト保存データを含む場合は復元された Web タブも順次再読み込みします。履歴・ダウンロード履歴・フォームデータだけの場合は起動時の再読み込みを行いません。

自動再読み込みと起動時自動削除は初期状態では無効です。Cookie やサイト保存データを削除すると、ログイン状態やサイトの設定が失われることがあります。

## 困ったとき・問い合わせ

- 拡張アイコンの赤い「!」は処理の失敗を知らせます。ポップアップを開くとバッジは消えますが、削除の成功を意味するものではありません。
- 削除ボタンに失敗が表示された場合は、設定を確認して再操作してください。大量のデータの削除やタブの再読み込みには時間がかかる場合があります。
- ポップアップの問い合わせボタンから、メール認証後に Kagayoi Support へ問い合わせできます。フォーム部品を読み込めない場合は Web の問い合わせ窓口へ移動します。

通常の削除処理は Chrome 内で完結します。問い合わせを利用すると入力情報を Kagayoi Support へ送信し、認証情報を拡張機能内に保存します。詳細は [プライバシーポリシー](docs/privacy-policy.md) を参照してください。

開発・検証・配布用 ZIP 作成については [AGENTS.md](AGENTS.md)、内部構造については [DESIGN.md](DESIGN.md) を参照してください。
